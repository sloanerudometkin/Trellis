# Trellis transparent PNG set

This folder contains six transparent-background PNGs based on the selected open-grid trellis and climbing-vine concept.

- Three standalone icons: white, black, and Moss Deep green.
- Three horizontal icon-and-wordmark logos: white, black, and Moss Deep green.

Green is the exact Trellis Moss Deep color: `#2C4E35`.

The white files may appear blank in viewers that use a white preview background. Place them over a dark color to see them.
